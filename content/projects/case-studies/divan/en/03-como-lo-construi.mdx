I built it in small pieces: one feature at a time, explained before coding it and tested before calling it done. That way every change can be understood in full and, if something breaks, it’s clear where to look.

The design started in Figma, with phone and desktop screens and a clickable prototype. When the code changed a screen, the design was updated too, so both told the same story.

The interface uses **UI Component**, my design system. What Diván needed and didn’t exist yet, like a date picker laid over the schedule, was solved there so other projects can use it too.

To make it feel fast, changes show up instantly, without waiting for the server, and navigation never reloads the page. There are four themes (Light, Warm, Pastel and Dark): they came from real use, because the white was tiring on the eyes.

Every piece was tested with made-up patients, never with real data.
