I organised it so each part reaches projects in the way that suits it best:

- **What must be the same everywhere**, like the style and the shared behaviours, is installed and updated as a single piece.
- **The visual components are copied into each project.** That way each one can adjust them to its needs without waiting on me to change anything.
- **A public catalogue** where every component can be seen in action, which also lets me check that everything still works after each change, across different browsers.

I moved forward in small stages, each one reviewed before calling it done. In October 2026 I published the first three versions, with over 40 components: from a simple button to filterable tables and charts.
