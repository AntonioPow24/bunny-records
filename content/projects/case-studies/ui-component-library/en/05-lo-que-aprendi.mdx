- **Use it the way a colleague would.** I set up a lab project that installs it from outside, following the guide to the letter. It found twelve issues the stories didn’t catch: copied code didn’t pass Next.js lint, the install guide was missing steps and some component combinations broke. They were fixed in the system, never patched in the lab.
- **Screenshots depend on the system.** Fonts rasterise differently on each operating system, so visual regression is only reliable inside the same Docker image CI uses.
- **Measure before recommending.** A large table without virtualisation costs about 1 ms per row; that’s why the docs recommend virtualising or paginating beyond roughly 100 rows.
- **Document for people and for agents.** Short documents, with one source for each decision, work just as well for a colleague as for a coding assistant.
