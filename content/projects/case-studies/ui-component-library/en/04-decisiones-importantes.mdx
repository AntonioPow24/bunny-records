- **Suggest, don’t impose.** Everything the system does is a starting point: text, language, limits or animations can be changed in each project without fighting it.
- **Hand over the code instead of hiding it.** Sooner or later a project needs something different. If the component lives inside the project, it can be adapted in no time.
- **Accessible from the start.** I chose a foundation built for keyboards, screen readers, different languages and touch screens, because adding that at the end always turns out worse.
- **Charts everyone can read.** Every chart also comes as a table, with colours that can be told apart even with colour blindness.
- **Get ready before promising stability.** Before calling the system stable, I reviewed names and options and wrote down how future changes will be made, so nobody gets caught by surprise.
