Every new project started the same way: building the same buttons, forms, dialogs and tables again, and wrestling once more with the details nobody sees but everyone notices, like making it work with a keyboard or explaining an error clearly. Whatever turned out well in one project stayed locked inside it.

UI Component was born to change that. It’s my design system: not a tool invented from scratch, but what had already worked in real projects, gathered and organised so it can be reused.

It has three parts:

- **A shared style** (colours, spacing, typography and motion) with the Bunny Records identity as its starting point.
- **Behaviours already solved**, such as searching, validating or uploading files, fixed once and improved in every project at the same time.
- **Accessible components** that each project can take and adapt to its liking.

Something new only gets in when a real project needs it. That’s how, for example, the file drop zone and the charts arrived.

I use it in my projects and it’s open to colleagues who want to make use of it. The catalogue can be seen at [ui.bunnyrecords.dev](https://ui.bunnyrecords.dev).
