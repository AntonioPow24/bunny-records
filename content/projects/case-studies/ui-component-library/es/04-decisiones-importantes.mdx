- **Defaults, nunca imperativos.** Todo comportamiento es un valor por defecto que el proyecto puede sustituir: mensajes, idioma, límites, movimiento y estilos. La precedencia es siempre la misma: componente, después configuración global y, al final, la prop de cada uso.
- **Copiar en vez de instalar los componentes.** Un proyecto acaba necesitando cambiar algo; con el código en casa lo cambia sin bifurcar el sistema. La lógica que no debe divergir sí va en paquetes.
- **React Aria en vez de las primitivas habituales.** El contrato pide IME, idiomas, táctil y un combobox de primer nivel, y ahí es donde más completo es.
- **Gráficas en SVG propio, sin biblioteca.** Cada gráfica lleva su tabla de datos para lectores de pantalla, recorrido con flechas y una paleta de datos validada para daltonismo.
- **Candados, no casos.** Ante entradas extremas, una guarda general en un solo punto (una escala nunca devuelve una coordenada no finita; una celda de estado siempre tiene nombre) en vez de código que persiga cada variante.
- **Congelar la API antes de la 1.0.** Antes de prometer estabilidad revisé nombres y props comunes, y escribí qué cuenta como cambio incompatible y cómo se retira algo.
