- **Usarlo como un colega lo usaría.** Monté un proyecto laboratorio que lo instala desde fuera, siguiendo la guía tal cual. Encontró doce problemas que las historias no veían: el código copiado no pasaba el lint de Next.js, faltaban pasos en la guía de instalación y algunas combinaciones de componentes fallaban. Se corrigieron en el sistema, nunca con parches en el laboratorio.
- **Las capturas dependen del sistema.** Las fuentes se rasterizan distinto en cada sistema operativo, así que la regresión visual solo es fiable dentro de la misma imagen de Docker que usa la CI.
- **Medir antes de recomendar.** Una tabla grande sin virtualizar cuesta en torno a 1 ms por fila; por eso la documentación recomienda virtualizar o paginar a partir de unas 100 filas.
- **Documentar para personas y para agentes.** Documentos cortos, con una fuente para cada decisión, sirven igual a un colega que a un asistente de código.
- **Dos asistentes, papeles separados.** Claude Code implementa cada lote y Codex lo revisa después, nunca a la vez. Yo decido el alcance y apruebo cada versión antes de publicarla.
