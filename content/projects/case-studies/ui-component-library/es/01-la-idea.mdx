Cada proyecto nuevo empezaba igual: volver a construir botones, campos, diálogos y tablas, y volver a resolver lo difícil de cada uno (el foco, el teclado, los errores, los estados de carga). Lo que salía bien en un proyecto se quedaba en ese proyecto.

UI Component es la respuesta: el sistema de diseño de la casa. No es un framework propio, sino lo ya probado, extraído y documentado para reutilizarlo:

- **Tokens** de color, espacio, tipografía y movimiento, con Bunny Records como tema por defecto.
- **Lógica sin DOM** (búsqueda, validación, paginación, subidas, idiomas) que se corrige una vez para todos.
- **Componentes React accesibles** que cada proyecto copia y puede editar.

La regla para crecer es la extracción: un patrón entra cuando un proyecto real lo necesita. Así llegaron, por ejemplo, la zona para soltar archivos (pensada para el conversor de documentos) o las gráficas y la tabla avanzada (para la plataforma educativa).

Es para mis proyectos y para colegas que quieran usarlo. El catálogo es público en [ui.bunnyrecords.dev](https://ui.bunnyrecords.dev); el repositorio, por ahora, es privado.
